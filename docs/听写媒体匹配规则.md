# 听写翻译媒体匹配

作品详情 → 更多 → 听写翻译：没有勾选时，对完整目录自动匹配；有勾选时，完全采用手动选择。匹配只准备待处理列表，检查列表后仍需点击开始。可返回作品页勾选文件来覆盖自动结果。

实现：`app/lib/services/dictation_media_matcher.dart`。本地判断只读取已加载的目录、文件名、时长和可用媒体地址，不额外请求网络，不下载或试听音频。

## 规则顺序

1. 遍历整部作品，保留有可用地址的音频、视频。过滤图片、台本、字幕、明确的宣传片/试听目录和纯 BGM 素材目录。独立 Free Talk / Cast Talk / PR Talk 保留；曲目标题中的“自己 PR”不算宣传片。
2. 先建立曲目身份：目录中的编码格式、音效版本和质量包装不参与身份；曲目编号、正文标题、声优、光盘、左右声道、剧情分支及特典目录参与身份。仅有编号的目录也保留。不会只按曲目编号跨目录合并。
3. 同一身份优先完整无效果音：`SEなし`、`SE無`、`効果音無し`、`SE・エフェクトなし`、`无效果音`、`无音效`、`no-se`、`no_se`、`no se`、`nonSE`、`SEless`、`声のみ`等。支持全角英数和大小写变化，允许目录标签、文件名前缀和后缀。
4. 完整无效果音优先于仅移除某一种音效（如射精音、时钟音、魔法音）；之后是降低音效的 `se_low` / `se-low` / `low_se` / `se reduced`，以及仅移除 BGM 的版本；最后回退普通版。`se_low` 不会当作完全无效果音。
5. 音效优先级相同，再按小体积格式取舍：`MP3 → AAC → M4A → Opus → OGG → WMA → FLAC → APE → WAV → AIFF → 其他媒体`。同格式且明确标注位深时选较低位深。不读取实际码率/文件大小，因此这是格式偏好，不保证文件字节数最小。无效果音 WAV 仍优先于普通 MP3。
6. 每首曲目单独回退：无效果音目录缺少的章节从普通目录补齐，不会为了固定一个目录而漏选。独立特典、EX、短片段和 Free Talk 不受最短时长限制。作为“特典”发布的本篇无效果音版本可替代普通本篇。
7. 明确标为“通し / 全パート / full track”等连续版，仅当同一语义目录至少两段章节的总时长覆盖它时才去掉。容差为章节数加 2 秒，补偿 API 整数截断；缺少时长或覆盖不明确时保留。
8. 同一个父目录下明确标注的简体、繁体、日文目录，可按“语言目录内的相对语义目录 + 曲目编号 + 时长”去重，允许不同语言的文件名完全不同。支持 `0 标题`、`Tr01_标题`、`l05_00／タイトル` 等编号格式，时长跨度最多 1 秒。先沿用无效果音/压缩格式优先级，条件相同再按日文、简体、繁体取舍。缺少对应章节、独立特典、不同声优/分支目录、不明编号、缺失时长或同一语言内编号有歧义时保留，不整批屏蔽某种语言。

未知的“微調整ver”、意义不明的 A/B/C 版本、不同声优、左右声道和无法确认重复的连续版保留。`MP3.mp3` / `WAV.wav` 这类没有曲目身份的文件也保守保留。命名不含标签时无法证明有无效果音；这是一套可手动覆盖的元数据规则。

## 参考与差异

参考 [beets Duplicates Plugin](https://beets.readthedocs.io/en/stable/plugins/duplicates.html) 的 `keys` 分组与 `tiebreak` 取舍机制。beets 面向本地音乐库及 MusicBrainz 元数据，不能直接用于远程 ASMR 文件树；这里以发布者的目录/曲目名构造身份键，不进行声纹、校验和或全文件比对。常规分组是哈希查找，不做全部曲目的两两模糊比较。

大目录执行参考 Flutter 官方 `compute`，本机 SDK 源码位于 `packages/flutter/lib/src/foundation/isolates.dart`：超过 512 个节点时在原生平台后台 isolate 中执行。小目录直接计算，避免 isolate 启动成本。Flutter Web 的 compute 使用当前事件循环，因此后台隔离的结论只适用于原生平台。

## 每次操作开销

自动匹配仅在进入听写页时运行一次，复用作品页的完整媒体索引；滚动、动画和每帧构建不触发匹配，新增每帧匹配次数为 0。相对原来的手动路径，增加一次全树标签扫描、哈希分组和结果排序；没有新增网络请求。复杂度为 `O(L + N + K log K)`、额外空间 `O(L + N)`，其中 L 是节点名和身份键的总长度，N 是节点数，K 是保留曲目数。

后台执行仍有输入树传递及结果回传成本，不能把计算耗时等同于整个页面打开耗时。下列数字来自 Windows 本机 Flutter 测试进程的重复计算，不代表发布版或手机帧耗时。
