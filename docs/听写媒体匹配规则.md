# 听写翻译媒体匹配

作品详情 → 更多 → 听写翻译：没有勾选时，对完整目录自动匹配；有勾选时，完全采用手动选择。匹配只准备待处理列表，检查列表后仍需点击开始。可返回作品页勾选文件来覆盖自动结果。

实现：`app/lib/services/dictation_media_matcher.dart`。本地判断只读取已加载的目录、文件名、时长和可用媒体地址，不额外请求网络，不下载或试听音频。

## 规则顺序

1. 遍历整部作品，保留有可用地址的音频、视频。过滤图片、台本、字幕、明确的宣传片/试听目录、纯 BGM 素材、`无人声 / ボイスなし / no_voice` 标签，以及明确的寝息、呼吸音、环境音等纯音条目。特典中的纯耳かき/耳舐め编号切片，以及音源/素材目录内“动作_角色_声道”形式的独立音效切片也排除；自身或父目录带对白、囁き、Free Talk 标记的素材条目保留；普通特典不因“动作_名称”形式而排除。正片不会仅因“耳かき”“助眠”“安眠”而删除，`無声音`囁き也不等于无人声。
2. 先建立曲目身份：目录中的编码格式、早期/通常版包装、音效版本和质量包装不参与身份；曲目编号、正文标题、声优、光盘、左右声道、剧情分支及独立特典目录参与身份。仅有编号的目录也保留。不会只按曲目编号跨目录合并。
3. 同一曲目优先早期版，识别 `早期購入版`、`早期版`、`初期購入版`、`初回限定版`、`early edition` 等目录或文件名标签，也处理版本目录外的 ♡/♥ 装饰。优先级为：早期版 → 音效条件 → 文件格式 → 语言。早期版中的独有特典保留，通常版只补齐尚未匹配的曲目；不整批删除通常版或另一份特典。
4. 同一版本身份内优先完整无效果音：`SEなし`、`SE無`、`効果音無し`、`SE・エフェクトなし`、`无效果音`、`无音效`、`no-se`、`no_se`、`no se`、`nonSE`、`SEless`、`声のみ`等。支持全角英数和大小写变化，允许目录标签、文件名前缀和后缀。
5. 完整无效果音优先于仅移除某一种音效（如射精音、时钟音、魔法音）；之后是降低音效的 `se_low` / `se-low` / `low_se` / `se reduced`，以及仅移除 BGM 的版本；最后回退普通音效版。`se_low` 不会当作完全无效果音。
6. 音效优先级相同，再按小体积格式取舍：`MP3 → AAC → M4A → Opus → OGG → WMA → FLAC → APE → WAV → AIFF → 其他媒体`。同格式且明确标注位深时选较低位深。不读取实际码率/文件大小，因此这是格式偏好，不保证文件字节数最小。同为早期版时，无效果音 WAV 仍优先于普通 MP3；早期版 WAV 优先于通常版 MP3。
7. 每首曲目单独回退：早期版或无效果音目录缺少的章节从其他目录补齐，不会为了固定一个目录而漏选。独立有对白特典、EX、短片段和 Free Talk 不受最短时长限制，无人声标签先于版本优先级排除。作为“特典”发布的本篇无效果音版本可替代同版本的普通本篇。
8. 明确标为“通し / 全パート / full track”等连续版，仅当同一语义目录至少两段章节的总时长覆盖它时才去掉。容差为章节数加 2 秒，补偿 API 整数截断；缺少时长或覆盖不明确时保留。
9. 同一个父目录下明确标注的简体、繁体、日文目录，可按“语言目录内的相对语义目录 + 曲目编号 + 时长”去重，允许不同语言的文件名完全不同。支持 `0 标题`、`Tr01_标题`、`l05_00／タイトル` 等编号格式，时长跨度最多 1 秒。先沿用早期版/无效果音/压缩格式优先级，条件相同再按日文、简体、繁体取舍。缺少对应章节、独立特典、不同声优/分支目录、不明编号、缺失时长或同一语言内编号有歧义时保留，不整批屏蔽某种语言。

未知的“微調整ver”、意义不明的 A/B/C 版本、不同声优、左右声道和无法确认重复的连续版保留。`MP3.mp3` / `WAV.wav` 这类没有曲目身份的文件也保守保留。命名不含标签时无法证明有无效果音；这是一套可手动覆盖的元数据规则。

## 参考与差异

参考 [beets Duplicates Plugin](https://beets.readthedocs.io/en/stable/plugins/duplicates.html) 的 `keys` 分组与 `tiebreak` 取舍机制。beets 面向本地音乐库及 MusicBrainz 元数据，不能直接用于远程 ASMR 文件树；这里以发布者的目录/曲目名构造身份键，不进行声纹、校验和或全文件比对。常规分组是哈希查找，不做全部曲目的两两模糊比较。

大目录执行参考 Flutter 官方 `compute`，本机 SDK 源码位于 `packages/flutter/lib/src/foundation/isolates.dart`：超过 512 个节点时在原生平台后台 isolate 中执行。小目录直接计算，避免 isolate 启动成本。Flutter Web 的 compute 使用当前事件循环，因此后台隔离的结论只适用于原生平台。

## 每次操作开销

自动匹配仅在进入听写页时运行一次，复用作品页的完整媒体索引；滚动、动画和每帧构建不触发匹配，新增每帧匹配次数为 0。相对原来的手动路径，增加一次全树标签扫描、哈希分组和结果排序；没有新增网络请求。复杂度为 `O(L + N + K log K)`、额外空间 `O(L + N)`，其中 L 是节点名和身份键的总长度，N 是节点数，K 是保留曲目数。

后台执行仍有输入树传递及结果回传成本，不能把计算耗时等同于整个页面打开耗时。下列数字来自 Windows 本机 Flutter 测试进程的重复计算，不代表发布版或手机帧耗时。
