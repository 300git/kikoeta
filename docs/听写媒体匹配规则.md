# 听写媒体匹配规则

## 匹配范围

作品详情中未勾选文件时，听写翻译会对整部作品的完整目录自动匹配，不受当前文件筛选范围影响。有勾选时采用手动选择，不执行自动匹配。

自动匹配仅接收有可用播放或下载地址的音频文件，按文件名末尾的扩展名判断，忽略大小写并兼容全角英数：

`MP3、AAC、M4A、Opus、OGG、WMA、FLAC、APE、WAV、AIFF、MKA`。

MP4、WebM、MKV、AVI、MOV、WMV、FLV、TS、M4V 等视频文件不参与匹配，即使位于早期版、特典或无效果音目录中也排除。只有视频的作品，自动匹配结果为空。图片、台本、字幕等非音频文件同样排除，`曲目.mp3.vtt` 不算音频。

## 宣传与无人声内容

- 排除明确标注为试听、体验版、宣传的目录或文件，如 `サンプル`、`体験版`、`sample`、`preview`、`demo`、`CM`、`PV`。独立的 `PR Talk`、`Free Talk` 等有对白音频保留。
- 排除纯 BGM、音效素材，以及明确标注 `无人声`、`ボイスなし`、`no_voice`、`voice off` 的内容。无人声排除先于早期版、音效和格式偏好。
- 排除明确的纯寝息、呼吸音、吐息、环境音、雨音、波音等曲目，包括相应编号或循环片段。
- 特典目录中的纯 `耳かき`、`耳舐め` 编号切片排除；音源或素材目录中“动作_角色_声道”形式的独立音效切片也排除。
- 音源或特典目录带有对白、囁き、语音、Free Talk 等标记时，不仅凭动作名称排除；明确标注无人声的内容仍排除。普通特典不因“动作_名称”的形式而排除。
- 正片不会仅因包含“耳かき”“耳舐め”“助眠”“安眠”而排除。`無声音`囁き、`睡眠用囁き`等有对白内容保留。

## 曲目身份与独立内容

先判断哪些候选属于同一曲目，再在同一曲目中取舍版本。

目录或文件名中的编码格式、早期版／通常版包装、音效标签和质量标记不参与曲目身份；曲目编号、正文标题、声优、光盘、左右声道、剧情分支及独立特典目录参与身份。仅有编号的目录也保留，不只凭编号跨目录合并。

不同声优、光盘、声道、分支或特典组分别保留。独立有对白特典、EX、短片段和 Free Talk 没有最短时长限制。以“特典”名义发布的本篇无效果音版本，可以替代同一曲目的普通本篇。

## 同曲目版本优先级

按以下顺序比较，前一项优先级高于后一项：

1. **早期版优先。**识别 `早期購入版`、`早期版`、`初期購入版`、`初回限定版`、`early edition` 等目录或文件名标签，兼容版本目录外的 ♡／♥ 装饰。早期购买特典独立保留，通常版补齐早期版缺少的曲目，不整批删除通常版。
2. **完整无效果音优先。**识别 `SEなし`、`SE無`、`効果音無し`、`SE・エフェクトなし`、`无效果音`、`无音效`、`no-se`、`no_se`、`no se`、`nonSE`、`SEless`、`声のみ`等。支持目录标签、文件名前后缀、大小写及全角英数。
3. **音效逐级回退。**完整无效果音 → 仅移除某类音效（如射精音、时钟音、魔法音）→ 降低音效的 `se_low`／`se-low`／`low_se`／`se reduced` 或仅去掉 BGM → 普通音效版。`se_low` 不等于完全无效果音。
4. **优先低存储占用格式。**前述条件相同时，按 `MP3 → AAC → M4A → Opus → OGG → WMA → FLAC → APE → WAV → AIFF → MKA` 取舍。同格式且双方均有明确位深时，选较低位深。此处按格式偏好判断，不读取实际文件大小或码率。
5. **语言副本去重。**满足下节条件时，先沿用早期版、音效和格式优先级；这些条件相同，再依次优先日文、简体、繁体。

每首曲目单独回退，不为固定选择某个目录而漏掉章节。因此，早期版 WAV 优先于通常版 MP3；同为早期版时，无效果音 WAV 优先于普通音效 MP3。条件完全相同则保留目录遍历中先出现的候选，最终结果按原目录顺序排列。

## 多语言副本

仅对同一父目录下明确标注的日文、简体、繁体目录进行语言副本识别，以“语言目录内的相对语义目录 + 曲目编号 + 时长”对应曲目，允许翻译后的标题完全不同。

支持 `0 标题`、`Tr01_标题`、`l05_00／タイトル` 等编号，归为同一曲目的时长跨度最多 1 秒，不通过逐个相邻比较扩大容差。

缺章、独有特典、不同声优或分支、不明编号、缺失时长，以及同一语言内编号有歧义的候选保留，不整批屏蔽某种语言。

## 连续版与不明版本

明确标为 `通し`、`全パート`、`full track` 等的连续版，只有在同一语义目录中至少两段非特典章节的总时长覆盖它时才排除，时长容差为“章节数 + 2 秒”。缺少时长、覆盖不明确或属于独立特典时保留。

未知的“微調整ver”、意义不明的 A／B／C 版本，以及 `MP3.mp3`／`WAV.wav` 这类无法确认曲目身份的文件保守保留。规则只依据目录、文件名、时长和可用地址判断，不分析实际音频；命名中没有标签时，不能确认是否存在效果音或对白。

## 必要示例

- **RJ01680559：早期版与通常版。**`♡早期購入版♡`优先匹配，早期版独有特典保留，通常版仅补缺失曲目。
- **RJ01716786：有对白特典与纯音赠品。**保留无效果音正片、有对白特典和 Free Talk；排除音源目录中独立的动作／角色／声道切片。
- **RJ01709662：简体、繁体、日文重复曲目。**按相对目录、编号和时长合并对应章节，条件相同时选择日文 MP3，独有章节仍保留。
- **RJ01415066：视频特典。**`初期購買特典`中的 MP4 不参与自动匹配，作品中的合格音频继续按上述规则选择。
